## 🔌 Como Implementar

### Opção 1: Usar Diretamente no WordPress

1. Acesse o painel do WordPress
2. Desative o Elementor para a página
3. Cole o conteúdo do `index.html` na área de HTML
4. Carregue o `styles.css` como stylesheet personalizado
5. Carregue o `script.js` como script personalizado

### Opção 2: Como Static Site

1. Clone este repositório
2. Abra o `index.html` em seu navegador
3. Customize conforme necessário
4. Publique em um host estático (GitHub Pages, Netlify, etc.)

### Opção 3: Integrar com WordPress Theme

1. Copie o CSS para `Aparência > CSS Personalizado`
2. Copie o JS para um plugin de scripts customizados
3. Use o HTML como template
